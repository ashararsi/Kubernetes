3. Prerequisites

  • Docker Desktop installed and running (whale icon in menu bar)
  • Kubernetes enabled in Docker Desktop: Settings → Kubernetes → Enable Kubernetes
  • kubectl (bundled with Docker Desktop)

Open a terminal and cd "/Users/apple/Downloads/files (1)" before running any commands.

4. Docker Only (no Kubernetes)

Build the image:

docker build -t construction-node-app:1.0 .

Run a container:

docker run --rm -d --name construction-welcome -p 3000:3000 construction-node-app:1.0
URLResult
http://localhost:3000App home page
http://localhost:3000/healthReturns ok

Stop:

docker stop construction-welcome

5. Kubernetes — First-Time Setup

  1. Open Docker Desktop and enable Kubernetes, wait until fully ready.
  2. Check context: 
    kubectl config get-contexts
    Active context (e.g. docker-desktop) should be marked CURRENT.
  3. Verify the cluster: 
    kubectl cluster-info
kubectl get nodes

6. Build Image and Deploy to Cluster

cd "/Users/apple/Downloads/files (1)"

docker build -t construction-node-app:1.0 .

kubectl apply -f deployment.yaml
kubectl apply -f service.yaml

Check status:

kubectl rollout status deployment/construction-app
kubectl get pods,svc -l app=construction-mgmt

You should see the pod READY 1/1 and Running.

7. Open the App in a Browser

Option A — Port Forward (Recommended)

kubectl port-forward svc/construction-app-svc 8080:80

Open http://localhost:8080 in your browser. Press Ctrl+C to stop.

Option B — NodePort

Service maps NodePort 30080. On Docker Desktop, Option A is more reliable.

8. Day-to-Day Commands

TaskCommand
List podskubectl get pods -l app=construction-mgmt
Logs (follow)kubectl logs -f deployment/construction-app
Describe (debug)kubectl describe pod -l app=construction-mgmt

Deployment detailkubectl describe deployment construction-app

9. Scale Replicas

kubectl scale deployment construction-app --replicas=2
kubectl get pods -l app=construction-mgmt

To make it permanent, edit spec.replicas in deployment.yaml and run kubectl apply -f deployment.yaml again.

10. Update After a New Image

  1. Build with a new tag: 
    docker build -t construction-node-app:1.1 .
  2. Set image: construction-node-app:1.1 in deployment.yaml, then: 
    kubectl apply -f deployment.yaml
kubectl rollout status deployment/construction-app

If keeping the same tag, just restart pods:

kubectl rollout restart deployment/construction-app

11. Cleanup

kubectl delete -f service.yaml --ignore-not-found
kubectl delete -f deployment.yaml --ignore-not-found

Docker-only container:

docker rm -f construction-welcome 2>/dev/null

12. What to Learn or Build Next

  1. Registry — Push to Docker Hub / GHCR; use full image name in Deployment.
  2. Secrets / ConfigMap — DB URLs, API keys; avoid hardcoding.
  3. Namespace — kubectl create namespace construction
  4. Ingress + TLS — Public hostname + HTTPS (cert-manager + Let's Encrypt).
  5. CI/CD — GitHub Actions: build → push → deploy.
  6. Resource limits — Tune resources in deployment.yaml.
  7. Monitoring — Centralised logs; Prometheus/Grafana.

15. Deploying on a Linux Server

15.1 Get the Project

Option A — Git clone:

sudo apt update && sudo apt install -y git
git clone https://github.com/ashararsi/Kubernetes.git
cd Kubernetes

Option B — Copy with rsync:

rsync -avz --exclude 'node_modules' "./files (1)/" user@YOUR_SERVER_IP:~/Kubernetes/

15.2 Install Docker Engine (Ubuntu)

sudo apt update
sudo apt install -y ca-certificates curl
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc

echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] \
  https://download.docker.com/linux/ubuntu $(. /etc/os-release && echo "${VERSION_CODENAME:-$VERSION_ID}") stable" \
  | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
sudo usermod -aG docker "$USER"

15.3 Run with Docker Only

docker build -t construction-node-app:1.0 .
docker run --rm -d --name construction-welcome -p 3000:3000 construction-node-app:1.0

15.4 Kubernetes on Linux

Path A — K3s (Single Server / VPS)

curl -sfL https://get.k3s.io | sh -
sudo mkdir -p ~/.kube
sudo cp /etc/rancher/k3s/k3s.yaml ~/.kube/config
sudo chown "$USER:$USER" ~/.kube/config
export KUBECONFIG=~/.kube/config

docker build -t construction-node-app:1.0 .
docker save construction-node-app:1.0 | sudo k3s ctr images import -
kubectl apply -f deployment.yaml -f service.yaml

Path B — MicroK8s

sudo snap install microk8s --classic
sudo usermod -aG microk8s "$USER"
microk8s status --wait-ready
alias kubectl='microk8s kubectl'
docker build -t construction-node-app:1.0 .
docker save construction-node-app:1.0 | microk8s ctr image import -
kubectl apply -f deployment.yaml -f service.yaml

Path C — Minikube

minikube start --driver=docker
eval $(minikube docker-env)
docker build -t construction-node-app:1.0 .
kubectl apply -f deployment.yaml -f service.yaml
minikube service construction-app-svc --url

16. Rocky Linux — Full Walkthrough

16.1 Update System

sudo dnf -y update
sudo dnf -y install git curl ca-certificates

16.2 Install Docker Engine

sudo dnf -y install dnf-plugins-core
sudo dnf config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repo
sudo dnf -y install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
sudo systemctl enable --now docker
sudo usermod -aG docker "$USER"

16.3 Clone Project

cd ~
git clone https://github.com/ashararsi/Kubernetes.git
cd Kubernetes

16.4 Quick Sanity Check (Docker only)

docker build -t construction-node-app:1.0 .
docker run --rm -d --name construction-welcome -p 3000:3000 construction-node-app:1.0
curl -sS http://127.0.0.1:3000/health
docker stop construction-welcome

16.5 Configure Firewall

sudo systemctl enable --now firewalld
sudo firewall-cmd --permanent --add-port=6443/tcp
sudo firewall-cmd --permanent --add-port=10250/tcp
sudo firewall-cmd --permanent --add-port=8472/udp
sudo firewall-cmd --permanent --add-port=30080/tcp
sudo firewall-cmd --reload

16.6 Install K3s

curl -sfL https://get.k3s.io | sh -
sudo systemctl status k3s --no-pager

16.7 Configure kubectl

mkdir -p ~/.kube
sudo cp /etc/rancher/k3s/k3s.yaml ~/.kube/config
sudo chown "$(id -u):$(id -g)" ~/.kube/config
chmod 600 ~/.kube/config
export KUBECONFIG="$HOME/.kube/config"
echo 'export KUBECONFIG="$HOME/.kube/config"' >> ~/.bashrc
kubectl get nodes

16.8 Build & Import Image into K3s

docker build -t construction-node-app:1.0 .
docker save construction-node-app:1.0 | sudo k3s ctr images import -
sudo k3s ctr images ls | grep construction-node-app

16.9 Deploy to Kubernetes

kubectl apply -f deployment.yaml -f service.yaml
kubectl rollout status deployment/construction-app --timeout=120s
kubectl get pods,svc -l app=construction-mgmt -o wide

16.10 Open the App

curl -sS http://127.0.0.1:30080/health

From your laptop: http://ROCKY_SERVER_IP:30080
